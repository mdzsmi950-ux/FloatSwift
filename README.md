# Float Cashflow

Native SwiftUI rewrite of Float Cashflow.

This first pass includes the existing core app behavior without onboarding:

- Accounts
- Confirmed/current balance
- Reserve balance and goal
- Bills
- Income
- Paid early bills
- Forward cashflow timeline
- Sinking date calculation
- Local JSON persistence

Open `FloatCashflow.xcodeproj` in Xcode and run the `Float Cashflow` scheme.
